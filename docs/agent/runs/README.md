# Agent run logs

Optional handoff notes for long or multi-session work. Prefer updating root [PROGRESS.md](../../PROGRESS.md) for short sessions.

## Naming

`YYYY-MM-DD-slug.md` — e.g. `2026-08-20-geo-sync.md`

## Template

```markdown
# Run: <slug>

- Date:
- Goal:
- Feature (FEATURES.md):
- Files read:
- Changes:
- Verify: `make verify` → pass/fail
- Handoff / next:
```
